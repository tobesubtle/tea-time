 1. 사용자는 관리자만 추가 수정 삭제 가능

1.(이메일과 비밀번호 이용)
2.**소셜로그인 사용하지 않음**

  - 변수 및 변수를 활용할 방법지정
  - 다수의 예시 관리
##탬플릿을 이용한 프롬프트 생성
##프롬프트 생성과정에서 선택한 탬플릿의 과거 사용이력 확인

  - 필요시 이 단계에서 pdf등 파일 첨부가능

##프롬프트를 실행한 결과 텍스트 수정
##프롬프트를 실행한 결과 텍스트를 txt파일로 저장하고 이를 **첨부**하여 메일로 송부
 1. (디폴트 메일주소는 자신의 메일) 
##기존에 생성된 프롬프트, 변수, 결과 관리(수정, 삭제)
- 일반사용자가 삭제시에는 실제 삭제하지 않고 보이지 않게만 수정(일반 사용자는 영구 삭제되었다고 생각하게 됨)
- 관리자가 삭제시에는 실제 삭제
- 관리자는 일반사용자가 삭제한(보이지 않게 처리한) 프롬프트 조회 및 최종 삭제
- Copy (클립보드 링크 복사 버튼 & 복사 완료 피드백)
- 이메일 발송
- ThumbsUp 좋아요 카운터 (클릭 시 카운트 증가/감소 연동)
기존에 생성된 프롬프트를 수정하여 재실행 가능
